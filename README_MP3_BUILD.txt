RETIREMENT PLANNING MP3 ANDROID PROJECT

This project is ready to upload through GitHub Desktop and build with GitHub Actions.

Changes in this version:
- The Privacy Policy speaker/audio feature is removed.
- The Income & Expense Setup (Page 2) speaker/audio feature is removed.
- The Directions speaker is disabled because directions.mp3 was not supplied.
- Five included MP3 recordings are bundled inside the APK.
- The existing HTML, calculations, sliders, charts, saving, and navigation are retained.

GitHub Desktop:
1. Extract this ZIP.
2. Copy everything inside the extracted folder into your local
   retirement-planning-app repository.
3. Replace files when Windows asks.
4. Open GitHub Desktop.
5. Commit with:
   Update APK pages and MP3 audio
6. Push origin.
7. Open the GitHub website > Actions.
8. Download the newest successful retirement-planning-debug-apk.
